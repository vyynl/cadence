## What's healthy

- **Boundaries hold.** `cadence_shared` contains no Phoenix/Ash/Postgrex
  references (grep: 0) and declares no web dependency; schemas, sync types,
  `GitStore`, and the LLM client live only there.
- **Data integrity is defended.** Content-addressed object store, pack
  validation, verify-before-delete repacking, pre-staging secret scans,
  quarantine, approval integrity checks, and fail-closed refusals.
- **The public surface is authorization-first.** Bearer PATs for `/sync/*`,
  CSRF/session/secure headers plus CSP for the browser, membership re-reads in
  every mutating LiveView event, and no `raw/1` on untrusted input.
- **The gate is automatic and reproducible.** One CI workflow runs the whole
  local gate, and every tool it calls is documented in `AGENTS.md`
  and `docs/spec.md` §11.
- **Tests are meaningful, not just numerous.** 1,241 tests with a measured
  87.98 / 82.18 / 82.09% per-app coverage, injected LLM/Docker fakes instead of
  process-level mocking, and regression tests for each bug fixed in this slice.

## Track evidence

### Architecture — 100

- `project_live.ex` is 178 lines with **7 direct dependencies** (the four
  LiveView floor modules plus `Components.DAG`, `Components.NodePane`, and
  `ProjectPane`), down from 19. `ProjectPane` owns the reads/state transitions
  and `Components.NodePane` owns the markup.
- `mix xref graph --format stats`: 163 tracked files, 34 compile edges, 65
  exports edges, 477 runtime edges, 5 cycles. Exactly one strongly-connected
  component carries compile edges — the Phoenix `endpoint.ex` ↔ `router.ex`
  wiring plus the web modules that `use Cadence.ServerWeb`; the other four are
  runtime-only (registry/supervisor/queue references), which OTP expects.
- The duplicated proposal-result markup is one `Components.ProposalResult`
  used by the public page and the review page; clean payloads render
  byte-identically (direct string-equality test).
- `ProjectPane` aggregates 15 outgoing dependencies. A further
  `ProjectPane.Repo` / `.Actions` split is optional and recorded, not required
  by the hotspot criterion.

### Performance — 100

- `Accounts.users_by_ids/1` is one `id in ids` read (`= ANY($1::uuid[])`);
  a telemetry counter pins one query for N ids and zero for an empty list.
- `Portfolio.preview_node/1` resolves the §4.4 cascade in one `LIMIT 1`
  statement (three-tier `CASE`, then `created_at DESC, id DESC`); a telemetry
  counter pins one query for the worst case.
- The public proposal result is memoized in a bounded, protected ETS cache
  (`CAD_PROPOSAL_CACHE_ENTRIES`, default 256). The key is content-derived
  (commit/tree SHAs plus the walk caps); errors and `:none` are never stored,
  and integrity checks bypass it.
- Caps remain in place everywhere they were before: DAG/repo walks, scan
  limits, run history paging, review queue (50), artifact list paging.
- Reviewed and accepted (not rubric deductions): the daemon's
  `SyncLedger.mark_docs_pushed/1` performs one conditional `Repo.get` +
  `Repo.update` per pushed node (bounded by the push batch, a background write
  path that must preserve the per-row docs state machine), and
  `Projects.rehydrate` reads one project per row at boot. Neither is on a
  request path.

### Security — 100

- `mix sobelow --exit medium` (from `apps/cadence_server`) → **exit 0**:
  0 high/medium, 26 low findings all triaged (25 `Traversal.FileModule` on
  server-derived paths, one `XSS.Raw` on MDEx-sanitized output).
- The `:browser` pipeline sets an exact CSP (`default-src 'self'`,
  `script-src 'self'`, `style-src` with the documented inline exception,
  `img-src 'self' https:`, `connect-src 'self'`, `object-src 'none'`,
  base-uri/form-action/frame-ancestors), pinned by controller tests and a
  headless LiveView smoke.
- `/sync/*` is rate-limited per authenticated user (`CAD_SYNC_RATE_LIMIT` 300
  per 60000 ms, non-positive disables) with `429` + `Retry-After` before any
  controller work; the meld limiter remains the inner per-project bound.
- `grep String.to_atom` under `apps/*/lib` matches only a comment explaining
  that it is never used. One `raw(@html)` remains, on MDEx-sanitized README
  output. Secrets are read from `CAD_*` env variables only.
- Authorization is re-read in mutating events: 11 `handle_event` clauses in
  the LiveViews, 43 membership/authorization references; approval/rejection
  and run actions re-check the acting membership before calling the context.
- Dependency advisories: four hackney 1.25.0 advisories are accepted risk
  (exact-ID ignore, time-boxed; spec §16). They are unreachable through
  Cadence's use of the library — see the rationale below.

## Exemptions recorded by the method

1. **A3 — Phoenix endpoint↔router compile cycle.** One compile cycle is
   Phoenix's normal wiring shape (the endpoint starts the router, the router
   pipes through the endpoint). Restructuring it would fight the framework for
   no runtime benefit. The other four xref cycles are runtime-only.
2. **P4 — LiveView streams.** The DAG is a whole-graph SVG layout, not a
   scrolling list; the review queue is capped at 50 and run history/artifacts
   are paged in the context. Streams would add client state without changing
   what is rendered.
3. **T3 — Mox.** `AGENTS.md` §8 forbids Mox in favour of injected test
   modules (`TestMeldLLM`, `TestDocsLLM`, `FakeDocker`). The rubric's
   `verify_on_exit!` line therefore does not apply.
4. **Accepted hackney advisories (risk, not a method exemption).** Four
   advisories (GHSA-gp9c-pm5m-5cxr high, GHSA-j9wq-vxxc-94wf moderate,
   GHSA-mp55-p8c9-rfw2 low, GHSA-pj7v-xfvx-wmjq moderate) affect hackney
   1.25.0, a prod transitive dependency pinned below 2.0 by
   `axiom_ai ~> 1.9` and `httpoison ~> 1.21`. No 1.x patch exists; the patched
   line is 4.x. Cadence only calls the operator-configured LLM host: no SOCKS5
   proxy, no user-supplied URL/query input, no `domain`/`path` options, no
   allowlist to bypass. Exact-ID ignore, revisit 2027-02-11 or when the pins
   relax / the transport moves to Req (spec §16).

## Residual risks (accepted, no rubric deduction)

- `lazy_html` 0.1.13 → 0.1.14 is a test-only patch left for a dependency batch.
- `Cadence.Shared.DAG` uses libgraph's default 32-bit `phash2` vertex
  identifier; a collision would merge two node ids. Probability is negligible
  at current project sizes. The hardening (`vertex_identifier: & &1`) is
  recorded, not adopted.
- Unmatched-path 404s are rendered before the browser pipeline, so they are
  the one browser surface without the CSP.
- The `/sync/*` limiter degrades to fail-open if the Hammer ETS owner restarts
  (the same exposure as the LLM limiter).
- Action containers share the host userns and `/out` has no quota; both remain
  deployment prerequisites (spec §8.4/§16).
- The CI workflow is syntax- and parity-validated locally, but its first real
  run happens when the repository is pushed with Actions enabled (no remote
  exists in this checkout).
- The audit's own advisory clone can be stale on a self-hosted runner; the CI
  guard proves populated + git HEAD, not freshness against the remote.
