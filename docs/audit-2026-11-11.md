## What is healthy

- **Boundaries hold.** `cadence_shared` has no Phoenix/Postgres/Ash; the daemon
  has no Phoenix; schemas, sync types, `GitStore`, and the LLM client live only
  in shared. The single compile cycle is Phoenix's endpoint↔router.
- **Data integrity is deliberately defended.** Content-addressed Git store,
  pack validation, verify-before-delete repacking, secret scans before staging,
  quarantine, integrity checks before approval, and fail-closed refusals.
- **The public surface is authorization-first.** Bearer PATs for the sync API,
  CSRF/session/secure headers for the browser, membership re-reads in every
  mutating LiveView event, and no `raw/1` on untrusted input.
- **Operational artifacts exist.** Server image + compose + migrate service,
  daemon release + migration task + systemd docs, a one-command demo stack, and
  a documented env contract (`CAD_*`, read in `runtime.exs`).
- **Tests are meaningful, not just numerous.** 1134 tests, targeted LiveView and
  request tests, injected LLM/Docker fakes, and regression tests for the bugs
  fixed here.
